Denne løsningen bruker Authorization Code + PKCE med krypterte, HttpOnly cookies. Feides ID-token verifiseres på serveren og sendes aldri til JavaScript eller Supabase.

OBS: Denne testen er ikke den endelige elevinnloggingen. Den er deaktivert inntil Netlify-miljøvariablene og Feides eksakte callback- og logout-adresser er registrert. Full Single Logout er først bekreftet når Feide sender nettleseren tilbake med korrekt tilstand.
